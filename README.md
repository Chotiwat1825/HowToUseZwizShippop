# คู่มือแนวทางการใช้งานระบบ Zwiz & Shippop สำหรับพนักงานขาย (ร้านมรุกข)

เว็บแอปพลิเคชันคู่มือปฏิบัติงานมาตรฐาน (SOP Playbook) สำหรับพนักงานขาย รวบรวมขั้นตอนการใช้งานระบบ **Zwiz.ai** และ **Shippop** ทั้งหมด 5 หมวดหมู่ พร้อมภาพประกอบชี้จุดสำคัญทุกขั้นตอน

## หมวดหมู่ในคู่มือ
1. **การส่งพัสดุผ่าน Zwiz (11 ขั้นตอน)** — ตั้งแต่เปิดแชทลูกค้า คัดลอกที่อยู่ เลือกขนส่ง จนถึงปริ้นใบปะหน้าพัสดุ
2. **วิธีดูสถานะการจัดส่ง (3 ขั้นตอน)** — วิธีกรองดูสถานะ จ่ายแล้ว / ส่งแล้ว / ยกเลิก และดูย้อนหลังตามช่วงวัน
3. **วิธีดูใบปะหน้าย้อนหลังใน Zwiz (3 ขั้นตอน)** — วิธีดาวน์โหลดไฟล์ใบปะหน้าย้อนหลังจากเมนู Shippop Orders
4. **วิธียกเลิกสินค้า & เปิดบิลใหม่ (8 ขั้นตอน)** — ขั้นตอนการแจ้งยกเลิกทั้งใน Shippop และ Zwiz พร้อมปุ่มคัดลอกคำสั่ง `#รับยอด` เพื่อเปิดบิลใหม่
5. **วิธีใช้งานเว็บ Shippop โดยตรง (9 ขั้นตอน)** — การสร้างรายการส่งพัสดุ (เปลี่ยนผู้ส่งเป็นร้านมรุกข) และการพิมพ์ใบปะหน้าซ้ำ

## วิธีนำไป Deploy บน GitHub Pages

โปรเจกต์นี้ถูกออกแบบเป็น **Zero-Build Static Web App** สามารถนำขึ้น GitHub Pages ได้ทันทีโดยไม่ต้องรันคำสั่ง Build:

### 1. สร้าง Repository บน GitHub
เข้าไปที่ [GitHub New Repository](https://github.com/new) ตั้งชื่อเช่น `how-to-use-zwiz-shippop` (เลือกเป็น Public) แล้วกด **Create repository**

### 2. อัปโหลดโค้ดขึ้น GitHub (รันใน PowerShell ที่โฟลเดอร์นี้)
```powershell
git branch -M main
git remote add origin https://github.com/<ชื่อผู้ใช้ของคุณ>/how-to-use-zwiz-shippop.git
git push -u origin main
```

### 3. เปิดใช้งาน GitHub Pages
1. ไปที่หน้า Repository บน GitHub > แท็บ **Settings** > เมนูซ้าย **Pages**
2. ในหัวข้อ **Build and deployment** > **Branch** ให้เลือก `main` และโฟลเดอร์ `/ (root)` แล้วกด **Save**
3. รอประมาณ 1 นาที จะได้ลิงก์เว็บไซต์สำหรับส่งให้พนักงานขายเปิดดูได้ทั้งบนมือถือและคอมพิวเตอร์ทันที
